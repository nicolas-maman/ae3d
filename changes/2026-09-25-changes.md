### Changes as files of their own

- A pull request now says what it changed in `changes/<date>-<what>.md`,
  not at the top of `CHANGELOG.md`. Every open pull request used to write
  to the same line, and each merge left the next one in conflict: four in
  a row on 2026-09-24. `tools/fold_changes.ae` folds the files into
  `## [current]`, newest first, and deletes them. It runs in a pull request
  of its own. `ci.sh` builds it.
- CONTRIBUTING.md says CI runs on every pull request, which it has since
  the workflow was changed; it used to say CI was started by hand.
